# Real Wikimedia Commons photos — toyota-gr-supra-a90

This labels file describes internal exploded mechanical parts, not exterior body labels. Only confidently visible components are mapped. Unseen internals remain empty instead of using unrelated generic parts. Turbo photo is an explicitly marked BMW B58 engine-family museum reference, not a unit verified as removed from a Supra. Intake photo is a tuned Supra with aftermarket induction. Exhaust photos show outlet/tailpipe context only, not exposed twin mufflers. Rear-subframe and differential detail crops share one real A90 display-assembly source.

## Reuse
Each image retains the license specified below. Preserve author attribution and follow ShareAlike where applicable. Images are real photographs, not renders or AI-generated images. Derivatives were cropped only as disclosed, resized without upscaling to maximum 2000px long side, and JPEG-recompressed at quality 85. Several label crops may share an original source; no claim is made that every file is a different camera exposure.
