# Credits — Ford F-150 Raptor sound kit

Every clip in this kit is a **real recording**, used under a free licence
(CC0, public domain, or CC BY 3.0). Nothing here is synthesised or given
a made-up credit. Clips were trimmed, faded and loudness-normalised
(target about −16 LUFS, peaks below −1 dBTP) for the site; that is an
adaptation, so CC BY works still need the attribution below.

Freesound has several even closer CC0 recordings (a delivery-truck
engine start, tyres on a gravel road, a RAM 1500 tailgate, desert wind).
Original-file download required a login, so those were **not** used.
Wikimedia Commons, OpenGameArt and Kenney originals were used instead.

### engine — Chevrolet Tahoe start and rev
- File: [Chevrolet Tahoe - engine and exhaust sound (YouTube FuORsRUyW30)](https://commons.wikimedia.org/wiki/File:Chevrolet_Tahoe_-_engine_and_exhaust_sound_(YouTube_FuORsRUyW30).opus)

- Licence: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0)
- Note: A 6-second start-and-rev was cut from the start of the recording. This is a Chevrolet Tahoe V8, used as a stand-in for the Raptor's 3.5-litre EcoBoost V6. Not a Raptor recording.
